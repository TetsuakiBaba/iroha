使い方

iroha のキー操作と、よく使う機能の使い方です。設定は、メニューバーの入力ソースのアイコン →「設定...」から開けます。

このページのキー操作と設定の場所は、Mac 版のものです。Windows 版と Linux 版では、キーや設定の場所が違うことがあります。入れ方はトップページの「はじめかた」にあります。

基本の操作

ローマ字で打つと、打つたびに文全体が変換し直されて表示されます。これをライブ変換と呼びます。表示が合っていれば Return で確定します。

キーはたらき
ローマ字で打つかなになり、続けて漢字に変換されます
Return表示している文を確定します
Space文を文節（意味のまとまりで区切った単位）に分けて、最初の文節の候補を出します。何も入力していないときはスペースを入れます
Backspace1 文字消します。表示はかなに戻ります
Esc候補 → 文節 → かな → 取り消し の順に 1 段ずつ戻ります
英数 / かな キー英字の入力 / 日本語の入力 に切り替えます（JIS キーボード）
Ctrl + Shift + J / ;日本語の入力 / 英字の入力 に切り替えます

文節と候補を直す

変換が思ったとおりでないときは Space を押します。文が文節ごとに分かれ、選んでいる文節に太い下線が付きます。

キーはたらき
← / →隣の文節に移ります
Shift + ← / →選んでいる文節を短く / 長くします。後ろの文節は自動で変換し直します
↑ / ↓ / Space候補の中で選ぶ候補を移します
1〜9その番号の候補を選びます
Tab候補がたくさんあるときに、表に広げます
Return選んだ候補のまま、文全体を確定します
文字キー← / → で文節を移したあとなら、選んでいる文節を打った文字から打ち直します（下の「文節を打ち直す」）。文節を移していなければ、文全体を確定して、打った文字から次の入力を始めます
Backspace選んでいる文節の読みを、後ろから 1 文字消します。文の途中の文節だけを消せます

文節を打ち直す

直したい文節を ← / → で選んでから文字を打つと、その文節だけを打ち直せます。確定してから消して打ち直す必要はありません。打つたびに文全体を新しい読みで変換し直すので、直した文節に合わせて前後の表記も変わります。

hasiwowataru「橋を渡る」→ Space → → で「渡る」へ → tukau
＝「箸を使う」（前の「橋」も「箸」に変わります）

  • 打ち直している間も、Return で全体を確定できます。Space を押すと今の文節の候補が出て、← / → を押すと隣の文節へ移ります。Esc を押すと打ち直す前に戻ります。
  • F6 などでひらがな・カタカナにした部分と英字は変わりません。ほかの文節で選んであった候補は、変換し直すと上書きされます。
  • ← / → で文節を移していないときに文字を打つと、文全体を確定して次の入力を始めます。Space で候補を選んだあと、そのまま続きを打てます。この動きは v0.19.0 からです（v0.17.0〜v0.18.1 では、文節を移していなくても打ち直しになっていました）。
  • 最初の文節を打ち直すときは、→ で移ってから ← で戻るか、Backspace で読みを消してから打ちます。

選び直して確定した変換は覚えておき、次に同じ読みを丸ごと打ったときに最初から出します。文節を打ち直して確定した変換は覚えません（辞書と学習）。

Ctrl のキーの組み合わせは、設定 > 入力 の「文字の種類を変えるキー」で、ほかの日本語入力に合わせて替えられます（v0.21.0 から。Mac 版・Windows 版・Linux 版とも）。

記号を入れる

z に続けてキーを 1 つ打つと、矢印やかぎかっこなどの記号が入ります。変換の候補から探さなくても、打つだけで入ります（v0.19.0 から）。

下の表の「z h」は、z を打ってから h を打つことです。

migizlhidari　→　「右→左」

文の途中で英字を入れる

Shift を押しながら英字を打つと、その間だけ英字になります。Shift を離すと日本語の入力に戻るので、モードを切り替えずに 1 回の Return で確定できます。

kyouha → Shift を押しながら A I → wotsukau → Return
＝「今日はAIを使う」

_ で囲んで英字にする

設定の「情報」→「開発者モード」を ON にすると、「入力」のタブに「区切り記号で英字を入力」が出ます。「記号で囲んだ部分を英字で入力する」を ON にすると、_ と _ で囲んで打った部分が、打ったとおりの英字になります。Shift を押し続けなくてよいので、長い英単語に向いています。

kyouha_iroha_wotsukau → Return
＝「今日はirohaを使う」

囲む記号は設定で変えられます。__ と続けて打つと、記号の _ そのものを入れられます。

確定を取り消す

確定した直後に Ctrl + Backspace を押すと、確定する前の状態に戻ります。ほかのキーを押したり、別のアプリに移ったりした後は取り消せません。

打ち間違いの訂正

設定の「入力」→「打ち間違いの訂正」の「打ち間違いを自動で直す」を ON にすると使えます。初めて ON にしたときに、訂正に使うデータを 1 回だけダウンロードします。

  • 入力の手が止まったときに、読みの打ち間違いを直してから変換します。
  • 直したときは、カーソルの下に「打った読み → 直した読み」が出ます。
  • 直してほしくなかったときは、すぐに Backspace を押すと元に戻ります。
  • 直すまでの待ち時間と、どのくらい控えめに直すかは、開発者モード（設定の「情報」）を ON にすると変えられます。
  • 初期設定では、3 文字までの短い読みは直しません。

予測変換

設定の「入力」→「予測変換」の「入力履歴から予測する」を ON にすると使えます。読みを 2 文字打つと、これまでに確定した言葉から続きの候補を 3 つまで出します。

  • Tab（または ↓）で候補を選びます。押すたびに次の候補に移ります。
  • 候補を選んだまま続きを打つと、その候補が入ってから続きが入ります。Return なら候補を入れて確定します。
  • 候補のもとになる入力の履歴は、予測変換が ON の間だけ残ります。設定から一覧を見たり消したりできます。

AI に書き換えを頼む

入力中の文を、登録しておいた指示で AI に書き換えてもらえます。指示は 3 つまで登録でき、初めは英訳・敬語・要約が入っています（ショートカットが付いているのは英訳だけです）。

あした会議やるから来て　→　⌥ + Return　→　Come to the meeting tomorrow.

  • 使う AI は設定の「モデル」→「AIサービス」で選びます。パソコンの中で動くもの（Apple Intelligence（macOS 26 以降）、Ollama、LM Studio）と、外部のサービス（Claude や OpenAI 互換のもの）があります。
  • 外部のサービスを選んだときは、書き換える文がそこに送られます。
  • 書き換えの途中で Esc を押すと取り消せます。また、結果が日本語のときは、確定する前に文節ごとに直せます。

辞書と学習

ユーザ辞書

メニューの「ユーザ辞書...」から、読みと言葉を登録できます。Mac の「システム設定」→「キーボード」→「ユーザ辞書」に登録してある言葉も取り込めます（Mac 側の辞書は書き換えません）。

専門辞書

設定の「辞書・学習」→「専門辞書」で、分野の用語・薬の名前・地名・駅名・人名などの辞書を 1 つずつ追加できます（20 種類）。辞書は、追加したときにダウンロードします。作り直されたときは、設定画面を開いたときに入れ直します。

  • 初期設定では、辞書の言葉は Space で開く候補の一覧にだけ出ます。ライブ変換には使いません。
  • 辞書ごとに「ライブ変換にも使う」を ON にすると、ユーザ辞書と同じく、ライブ変換にも出ます。ただし、読みが同じ言葉が 2 つ以上あるものと、読みよりずっと長いものは使いません。

変換の学習

Space で候補を選び直して確定すると、その変換を覚えます。次に同じ読みを丸ごと打ったときに最初から出します。文節を打ち直して確定した変換と、声で入れた文は覚えません。設定の「辞書・学習」で、覚えた内容を 1 件ずつ直したり消したりできます。

日付や時刻を入れる（変換ルール）

メニューの「変換ルール...」で、読みと出力の組を登録できます。登録した出力は Space で開く候補の一覧に出ます。出力に日付や時刻を書いておくと、変換するたびにその日の値になります。初めから「きょう」「あした」「いま」などが入っています。

きょう → 2026/11/06　　いま → 14:05

プライベートモード

ON の間は、変換の学習・変換記録・入力の履歴・予測変換・ユーザ辞書と、専門辞書の「ライブ変換にも使う」を止めます。メニュー、設定、または Ctrl + Option + P で切り替えられ、ON の間はカーソルの横に鍵のマークが出ます。

「こえ」モード

設定の「入力」のタブにある「「こえ」モード」を ON にします（初期設定は OFF）。今使えるのは Mac 版（macOS 26 以降）だけです。マイクの使用は設定画面から許可します。

  • 決めたキー（初期設定は右 ⌘。右 Option・fn も選べます）を押している間だけ録音し、離すと、話した内容が確定されずに入力中の文字として入ります。
  • 音声認識が出した漢字かな交じりの結果を読み（ひらがな）に戻してから、キーボードで打ったときと同じかな漢字変換に渡します。Space で開く候補の一覧・文節の打ち直し・続きのキー入力・Return での確定を、打った文と同じように使えます。
  • 話している間は、音声認識の途中の結果が入力中の文字として見えます。
  • 読みは音声認識の表記から求め直すので、人名等で取り違えることがあります。そのときは、Space で開く候補の一覧か、文節の打ち直しで直します。英字・数字は読みに戻さず、音声認識の表記のまま入ります。
  • 「えー」「あー」のような言いよどみは、AI に書き換えを頼む機能で除けます。言いよどみを除く指示を登録しておき、声で入れたあとに、その指示のショートカットのキーを押します。
  • 英数の入力に ABC やほかの入力ソースを使っている場合は、同じ節の「iroha 以外の入力ソースでも使う」を ON にします（初期設定は OFF、v0.21.0 から）。キーを押すと入力ソースを iroha に切り替えて録音を始め、確定したあとも iroha のままです。アクセシビリティの許可が要ります。
  • 音声認識はお使いの Mac の中で行い、音声を外部に送りません。声で入れた文は、変換の学習・入力の履歴に残しません。
