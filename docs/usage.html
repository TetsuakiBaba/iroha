使い方

iroha のキー操作と、よく使う機能の使い方です。設定は、メニューバーの入力ソースのアイコン →「設定…」から開けます。

基本の操作

ローマ字で打つと、打つそばから変換された文が表示されます（ライブ変換）。表示が合っていれば Return で確定します。

キーはたらき
ローマ字で打つかなになり、続けて漢字に変換されます
Return表示している文を確定します
Space文を区切りごとに分けて、最初の区切りの候補を出します。何も入力していないときはスペースを入れます
Backspace1 文字消します。表示はかなに戻ります
Esc候補 → 区切り → かな → 取り消し の順に 1 段ずつ戻ります
英数 / かな キー英字の入力 / 日本語の入力 に切り替えます（JIS キーボード）
Ctrl + Shift + J / ;日本語の入力 / 英字の入力 に切り替えます

区切りと候補を直す

変換が思ったとおりでないときは Space を押します。文が区切り（文節）ごとに分かれ、選んでいる区切りに太い下線が付きます。

キーはたらき
← / →隣の区切りに移ります
Shift + ← / →選んでいる区切りを短く / 長くします。後ろの区切りは自動で変換し直します
↑ / ↓ / Space候補の中で選ぶ候補を移します
1〜9その番号の候補を選びます
Tab候補がたくさんあるときに、表に広げます
Return選んだ候補のまま、文全体を確定します
文字キー選んでいる区切りを、打った文字から打ち直します（下の「区切りを打ち直す」）

区切りを打ち直す

直したい区切りを ← / → で選んで、そのまま文字を打つと、その区切りだけを打ち直せます。確定してから消して打ち直す必要はありません。打つたびに文全体を新しい読みで変換し直すので、直した区切りに合わせて前後の表記も変わります。

hasiwowataru「橋を渡る」→ Space → → で「渡る」へ → tukau
＝「箸を使う」（前の「橋」も「箸」に変わります）

  • 打ち直している間は、Return で全体を確定、Space で今の区切りの候補、← / → で隣の区切りへ移ります。Esc で打ち直す前に戻ります。
  • F6 などでひらがな・カタカナにした部分と英字は変わりません。ほかの区切りで選んであった候補は、変換し直すと上書きされます。
  • v0.17.0 から、区切りを直している間に文字を打つと打ち直しになります（それまでは全体を確定して次の入力を始めていました）。続きを打つときは、先に Return で確定します。

選び直して確定した変換は覚えておき、次に同じ読みを打ったときに最初から出します（辞書と学習）。

ひらがな・カタカナ・英数

キー表示
F6 または Ctrl + Uひらがな
F7 または Ctrl + Iカタカナ
F8 または Ctrl + O半角カタカナ
F9 または Ctrl + P全角英数（打ったキーのまま）
F10 または Ctrl + T半角英数（打ったキーのまま）

こうして決めた部分は、続けて打ってもそのままの形で残ります。

文の途中で英字を入れる

Shift を押しながら英字を打つと、その間だけ英字になります。Shift を離すと日本語の入力に戻るので、モードを切り替えずに 1 回の Return で確定できます。

kyouha → Shift を押しながら A I → wotsukau → Return
＝「今日はAIを使う」

_ で囲んで英字にする

設定の「情報」→「開発者モード」を ON にすると、「入力」のタブに「区切り記号で英字を入力」が出ます。「記号で囲んだ部分を英字で入力する」を ON にすると、_ と _ で囲んで打った部分が、打ったとおりの英字になります。Shift を押し続けなくてよいので、長い英単語に向いています。

kyouha_iroha_wotsukau → Return
＝「今日はirohaを使う」

囲む記号は設定で変えられます。__ と続けて打つと、記号の _ そのものを入れられます。

確定を取り消す

確定した直後に Ctrl + Backspace を押すと、確定する前の状態に戻ります。ほかのキーを押したり、別のアプリに移ったりした後は取り消せません。

打ち間違いの訂正

設定の「入力」→「打ち間違いの訂正」を ON にすると使えます。初めて ON にしたときに、訂正に使うデータを 1 回だけダウンロードします。

  • 入力の手が止まったときに、読みの打ち間違いを直してから変換します。
  • 直したときは、カーソルの下に「打った読み → 直した読み」が出ます。
  • 直してほしくなかったときは、すぐに Backspace を押すと元に戻ります。
  • 直すまでの待ち時間と、どのくらい控えめに直すかを設定で変えられます。
  • 初期設定では、3 文字までの短い読みは直しません。

予測変換

設定の「入力」→「予測変換」を ON にすると使えます。読みを 2 文字打つと、これまでに確定した言葉から続きの候補を 3 つまで出します。

  • Tab（または ↓）で候補を選びます。押すたびに次の候補に移ります。
  • 候補を選んだまま続きを打つと、その候補が入ってから続きが入ります。Return なら候補を入れて確定します。
  • 候補のもとになる入力の履歴は、予測変換が ON の間だけ残ります。設定から一覧を見たり消したりできます。

AI に書き換えを頼む

入力中の文を、登録しておいた指示で AI に書き換えてもらえます。指示は 3 つまで登録でき、初めは 1 つ目に英訳が入っています。

あした会議やるから来て　→　⌥ + Return　→　Come to the meeting tomorrow.

  • 使う AI は設定の「モデル」→「AI サービス」で選びます。Apple Intelligence（macOS 26 以降）、Ollama、LM Studio のように Mac の中で動くものと、Claude や OpenAI 互換のサービスのように外部のものがあります。
  • 外部のサービスを選んだときは、書き換える文がそのサービスに送られます。
  • 書き換えの途中で Esc を押すと取り消せます。結果が日本語のときは、確定する前に区切りごとに直せます。

辞書と学習

ユーザ辞書

メニューの「ユーザ辞書…」から、読みと言葉を登録できます。Mac の「システム設定」→「キーボード」→「ユーザ辞書」に登録してある言葉も取り込めます（Mac 側の辞書は書き換えません）。

変換の学習

Space で候補を選び直して確定すると、その変換を覚えます。次に同じ読みを打ったときに最初から出します。設定の「辞書・学習」で、覚えた内容を 1 件ずつ直したり消したりできます。

日付や時刻を入れる（変換ルール）

メニューの「変換ルール…」で、読みと出力の組を登録できます。出力に日付や時刻を書いておくと、変換するたびにその日の値になります。初めから「きょう」「あした」「いま」などが入っています。

きょう → 2026/11/06　　いま → 14:05

プライベートモード

ON の間は、変換の学習・入力の履歴・予測変換・ユーザ辞書を止めます。メニュー、設定、または Ctrl + Option + P で切り替えられ、ON の間はカーソルの横に鍵のマークが出ます。

「こえ」モード

設定の「情報」→「開発者モード」を ON にすると、「入力」のタブに「「こえ」モード」が出ます（初期設定は OFF、macOS 26 以降）。マイクの使用は設定画面から許可します。

  • 決めたキー（初期設定は右 ⌘。右 Option・fn も選べます）を押している間だけ録音し、離すと、話した内容が確定されずに入力中の文字として入ります。
  • 音声認識が出した漢字かな交じりの結果を読み（ひらがな）に戻してから、キーボードで打ったときと同じかな漢字変換に渡します。Space の候補・区切りの打ち直し・続きのキー入力・Return での確定が、打った文と同じようにできます。
  • 話している間は、音声認識の途中の結果が入力中の文字として見えます。
  • 読みは音声認識の表記から求め直すので、人名などで取り違えることがあります。Space の候補か区切りの打ち直しで直します。英字・数字は読みに戻さず、音声認識の表記のまま入ります。
  • 音声認識はこの Mac の中で行い、音声を外部に送りません。声で入れた文は、変換の学習・入力の履歴に残しません。

タブおもな項目
