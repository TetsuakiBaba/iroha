Mac のための文字入力IROHA

文字入力のいろは

iroha（いろは）は、Mac のための文字入力です。
キーボードで打った文字も、声で入れた言葉も、同じ変換で文にします。
機能と機能、人と人をつなげることを、文字入力の基本と考えて作っています。

iroha-kkc かな漢字変換モデル

速くて正確な、
iroha のための変換モデル

iroha-kkc は、iroha のために一から作ったかな漢字変換の AI です。打つたびに変換をやり直すライブ変換に向けて、速さを第一に設計しました。

ライブ変換に慣れるほど、この変換の速さの心地よさに気がつくはずです。

  • 変換にかかる時間は、これまでの代表的な AI のかな漢字変換モデル（zenz）の半分以下。3,253 問のテストでは平均 0.024 秒でした（zenz は 0.063 秒）。
  • 正確さは同じかそれ以上。3,253 問の変換のテストで、比べたモデルより多く正解しました。公開されている 200 問のテスト（AJIMEE-Bench）でも、同じ水準の正解率です。

打ち間違いの訂正TYPO CORRECTION

iroha-typo 打ち間違い訂正モデル

打ち間違いを、
手が止まったときに直す

iroha-typo は、変換の前に「読み」の打ち間違いを直す小さな AI です。入力の手が止まったときに読みを見直し、直してから漢字にします。

  • 打ち間違いの約 4 件に 3 件を直し、正しく打った文は 1 文も書き換えませんでした。（iroha のために書き下ろした 200 文のテストで）
  • 直したらカーソルの下に知らせます。直してほしくなかったときは、すぐに Backspace を押すと元に戻ります。
  • 最初は OFF です。設定で ON にしたときに、訂正に使うデータを 1 回だけダウンロードします。

    確定せずに打ち直す

    スペースキーで文節変換に入り、直したい文節を ← → で選んで、そのまま文字を打ちます。確定してから消して打ち直す必要はありません。

    • Return で全体を確定、スペースキーで今の文節の候補、Esc で打ち直す前に戻ります。
    • 設定は要りません（v0.17.0 から）。文節変換中に文字を打つと打ち直しになるので、続きを打つときは先に Return で確定します。

    キーボードで直す

    決めたキー（初期設定は右 ⌘）を押している間に話した内容が、確定されずに入力中の文字として入ります。

    • 打った文と同じかな漢字変換に渡します。音声認識が出した漢字かな交じりの結果を読み（ひらがな）に戻してから変換するので、スペースキーの候補・文節の打ち直し・続きのキー入力が、打った文と同じようにできます。

    • 使うには、設定 > 情報 で開発者モードを ON にし、設定 > 入力 >「こえ」モード を ON にします（初期設定は OFF、macOS 26 以降）。マイクの使用は設定画面から許可します。

    Mac の
    なかで

    打った文字は、外に送りません

    かな漢字変換も打ち間違いの訂正も、この Mac の中だけで行います。iroha が通信するのは、アップデートの確認と、変換に使うデータのダウンロードのときだけです（どちらも GitHub から）。

    例外は「AI に書き換えを頼む」機能で、外部の AI サービス（Claude や OpenAI 互換のサービスなど）を自分で選んだときだけ、その文がそのサービスに送られます。Mac の中で動く Apple Intelligence や Ollama を選べば、外には送られません。

    パスワードの入力欄では、macOS が日本語入力そのものを止めるので、iroha には文字が届きません。

    質問と答えFAQ

    よくある質問

    本当に無料ですか？

    無料です。iroha はオープンソースで、ソースコードを GitHub で公開しています。

    打った文字がどこかに送られることはありますか？

    ありません。変換はこの Mac の中で行います。外部の AI サービスを自分で選んで「AI に書き換えを頼む」機能を使ったときだけ、その文がそのサービスに送られます。

    Intel の Mac や Windows で使えますか？

    今は Apple シリコン（M1 以降）の Mac だけに対応しています。

    入力ソースの一覧に iroha が出てきません。

    インストールの直後は一覧に出ないことがあります。一度ログアウトしてログインし直してから、もう一度追加してください。

    入力メニューで iroha が灰色になって選べません。

    ほかのアプリがパスワード入力のための保護（セキュア入力）を続けているときに起きます。そのアプリのパスワード欄を閉じるか、アプリを終了すると戻ります。iroha は、原因になっているアプリの名前を画面に知らせます。

    打ち間違いの訂正が、正しく打った言葉を変えてしまいました。

    直した直後に Backspace を押すと元に戻ります。訂正の回数が多いと感じるときは、設定の「入力」→「打ち間違いの訂正」で訂正を控えめにできます。

    やめるときはどうすればよいですか？

    iroha の設定 →「情報」→「iroha をアンインストール…」で、入力ソースからの削除とアプリの削除まで行います。辞書などのデータも一緒に消すかを選べます。

    不具合を見つけたとき、要望があるときは？

    GitHub の Issues にお寄せください。

    開発者モード

    細かな調整や、試験的な機能の説明です。ふだん使うだけなら、読まなくても困りません。

    iroha の 設定 > 情報 > 開発者向け「開発者モード」を ON にすると、設定画面に次の項目が増えます。OFF に戻すと項目が見えなくなるだけで、変えた設定はそのまま効きます（推論の時間の表示だけは止まります）。この設定はほかの Mac と同期しません。

    自分の入力で追加学習（試験的）

    確定した変換の記録を使って、かな漢字変換のモデルに自分の文章の癖を覚えさせる機能です（LoRA と呼ばれる方法）。元のモデルは変えずに、小さな追加のファイル（アダプタ）を作ります。学習はこの Mac の中で行い、記録をどこにも送りません。iroha-kkc と zenz のモデルで使えます。

    1. 設定 > 辞書・学習 > 変換記録の「確定した変換を記録する」を ON にして、ふだんどおり使います。記録されるのは、前に書いた文があるところでの確定だけです。
    2. 記録が 30 件以上たまったら、設定 > モデルの「自分の入力で追加学習」で「学習を開始」を押します。数十秒から数分かかり、その間は GPU を使います。
    3. 結果を見ます。今のモデルが「間違えていた変換」をいくつ当てられるようになったかと、「できていた変換」をいくつ保てたかが並びます。
    4. よければ「このアダプタを使う」を押して、iroha を再起動します。

    記録が増えるほど、自分の文章に合った学習になります。「できていた変換」が減ったときは、そのアダプタは使わずに、記録が増えてからもう一度試してください。

    これまでの歩みHISTORY

    iroha ができるまで

    卒業研究で触れたかな漢字変換から、GenGo を経て、今の iroha までの主な出来事です。

    1. 学生時代

      かな漢字変換の卒業研究

      稲永 紘之 先生の指導のもとで、「一括変換処理方式におけるカナ漢字変換システムの構築」に取り組む。いつか自分のかな漢字変換を作りたい、という思いはここから。

    2. 2025年9月

      GenGo を作る

      はじめはかな漢字変換を作るつもりで、IMESidecar という名前で開発を始めたが、AI で文章を変換する機能が面白く、選んだ文を AI で翻訳・校正・書き換える Mac のアプリ GenGo に特化した。9月4日に最初の版を公開。

    3. 2026年5月

      GenGo が Product Hunt に

      新しい製品を紹介する英語のサイト Product Hunt に GenGo が掲載され、その日の順位で 26 位（77 ポイント）に入る。

    4. 2026年8月

      iroha の開発を始める

      GenGo を使ううちに、AI で文章を変換する機能は、日本語入力そのものに組み込んだほうがよいと考えるようになる。言語モデル（zenz）で文全体を読んで変換する Mac の日本語入力として、iroha の開発を始める。8月30日に最初の版（0.4.0）を GitHub で公開。

    5. 8月31日

      ユーザ辞書・変換の学習・AI 変換

      macOS のユーザ辞書の取り込み、直した変換を覚える学習、AI に頼んで書き換える機能を足す。GenGo の、選んだ文を AI で書き換える機能も iroha に取り込む。

    6. 8月末〜9月

      LLM-jp を元にした変換モデルの実験（うまくいかず）

      公開されている日本語の言語モデル llm-jp-3-150m を、かな漢字変換用に学習し直す実験をする。学習は順調に進んだように見えたのに、変換の正解率は zenz に大きく届かなかった（200 問のテストで 68.5%、zenz は 84.5%）。単語を単位にした語彙が、読みを 1 文字ずつ漢字に直す変換には合わないと考え、文字を単位にしたモデルを一から作る方針に切り替える。

    7. 9月1日

      Windows 版の試作

      Windows の入力のしくみで動く版を試作する（公開はまだしていません）。

    8. 9月8日

      候補を辞書から出す

      azooKey の辞書で変換の候補を作り、言語モデルで並べ替えるようにする。

    9. 9月10日

      前に書いた文に合わせて変換

      アプリに書いてあるカーソルの手前の文を読み、変換の手がかりにする。

    10. 9月11日

      自分の変換モデルを作り始める

      LLM-jp の実験をふまえ、iroha のための、文字単位で小さく速い変換モデルの設計と学習を始める。
